# Writing for humans

Write for the reader's decision or task. They should find the current answer, evidence, and next step without excavating prose.

## Workflow

1. Identify the reader, their question, and the document's destination. Ask only when an unknown would materially change the result.
2. Read existing material fully. Preserve useful facts, links, structure, and voice.
3. Present the current reasoning directly. Remove superseded framing; include revision history only when traceability matters.
4. Lead with the answer or purpose, then evidence, detail, and references.
5. Choose the smallest form that carries the relationship:

| Content | Form |
| --- | --- |
| Reasoning or nuance | Short prose |
| Parallel points or steps | List |
| Repeated comparison | Table |
| Flow, sequence, or hierarchy | Diagram |
| Critical exception | Callout |

Use Mermaid only when the destination renders it. Visuals must clarify, not decorate.

6. Cut repetition, throat-clearing, generic transitions, inflated claims, and irrelevant background. Keep evidence, caveats, and concrete examples.

## Final check

- Headings state the current claim or a plain topic, never how the document evolved.
- Paragraphs make one move; lists stay parallel; table cells stay short.
- Citations sit beside claims. Facts, inferences, recommendations, and uncertainty remain distinguishable.
- A 30-second scan reveals the purpose, conclusion, evidence, and next step.
- Revise the document itself rather than appending another summary.
