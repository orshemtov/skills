# Skills

[![skills.sh](https://skills.sh/b/orshemtov/skills)](https://skills.sh/orshemtov/skills)

My personal collection of Agent Skills: skills I use, write, and curate for real software work. Shared publicly so others can install, adapt, and improve them.

## Install

```sh
npx skills@latest add orshemtov/skills
```

## Skills

- [`read-the-docs`](./read-the-docs) — Research authoritative technical documentation before planning or implementation.

## Curated upstreams

- [Impeccable](https://github.com/pbakaus/impeccable) — Frontend design, critique, and UI quality workflows.
- [Ponytail](https://github.com/DietrichGebert/ponytail) — Minimal, YAGNI-oriented implementation and over-engineering review.
